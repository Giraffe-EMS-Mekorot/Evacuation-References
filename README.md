# tteudot-agent

סוכן שקורא תעודות פינוי פסולת (PDF/תמונות, כולל תעודות כתובות ביד) ומחלץ מהן
מידע מובנה לקובץ Excel מרוכז אחד, באמצעות מודל הראייה (vision) של Claude.

## התקנה

```bash
pip install -r requirements.txt
```

ודא שקובץ `.env` בתיקיית הפרויקט מכיל:

```
ANTHROPIC_API_KEY=sk-ant-...
```

ניתן גם להגדיר `CLAUDE_MODEL` ב-`.env` כדי לשנות את המודל המשמש לחילוץ
(ברירת המחדל: `claude-sonnet-5`).

## שימוש

1. הכניסו קבצי תעודות (`.pdf`, `.jpg`, `.jpeg`, `.png`) לתיקיית `input/`.
2. הריצו:

   ```bash
   python main.py
   ```

3. התוצאה תישמר ב-`output/ריכוז_תעודות.xlsx` - שורה אחת לכל תעודה.
   שורות עם רמת ביטחון "נמוכה" מסומנות באדום ו"בינונית" בצהוב, כדי לאתר
   בקלות תעודות שדורשות בדיקה ידנית.

לעיבוד קובץ בודד בלבד (שימושי בזמן פיתוח/בדיקה):

```bash
python main.py --file <שם_קובץ>
```

## ממשק אינטרנט (Streamlit)

חלופה גרפית ל-`main.py` שרצה כשרת מקומי ברשת המשרד - העלאת קבצים בגרירה-והשלכה
דרך הדפדפן במקום להעתיק אותם לתיקיית `input/`, טבלת תוצאות חיה עם אותה צביעה
אדום/צהוב לפי רמת ביטחון, וכפתור הורדה לקובץ `output/ריכוז_תעודות.xlsx`
המעודכן. משתמשת באותו pipeline בדיוק (`app/pipeline.py`, `app/extractor.py`),
כך שהחילוץ זהה בשני הממשקים.

האפליקציה מוגנת במסך כניסה עם סיסמה משותפת (ראו "פריסה בענן" למטה) - כדי
להריץ אותה מקומית צריך גם קובץ `.streamlit/secrets.toml` (לא נכנס ל-git)
עם `APP_PASSWORD`, בנוסף ל-`.env` הרגיל למפתח ה-API:

```bash
cp .streamlit/secrets.toml.example .streamlit/secrets.toml
# ואז לערוך את הקובץ ולמלא סיסמה משלכם
```

הרצה:

```bash
streamlit run streamlit_app.py
```

הפקודה פותחת דפדפן אוטומטית בכתובת `http://localhost:8501`, וגם מדפיסה
בטרמינל שתי כתובות:

```
Local URL:   http://localhost:8501
Network URL: http://<כתובת-ה-IP-של-המחשב>:8501
```

כדי לשתף עם אנשים אחרים במשרד: ודאו שהמחשב שמריץ את השרת ואנשים אלה מחוברים
לאותה רשת Wi-Fi/LAN, ואז שלחו להם את ה-**Network URL** (לא את ה-Local URL -
זו עובדת רק על המחשב המריץ). אם הכתובת לא נטענת אצלם, כנראה שחומת האש
(Firewall) של Windows חוסמת את הפורט 8501 - יש לאשר גישה עבור Python/Streamlit
ברשת הפרטית (Private network) בהגדרות חומת האש.

השרת חד-משתמש-בו-זמנית מבחינת כתיבה לקובץ הפלט: אם שני אנשים לוחצים "עבד
תעודות" בו-זמנית מדפדפנים שונים, הרצה אחת עלולה לדרוס את השנייה בקובץ.

הרצה מקומית שימושית לפיתוח/בדיקה; לשיתוף קבוע עם עמיתים במשרד בלי להשאיר
מחשב אישי דלוק עם שרת פתוח, ראו פריסה בענן למטה.

## פריסה בענן (Streamlit Community Cloud)

האפליקציה מוגנת בסיסמה משותפת (מסך כניסה לפני כל תוכן) ומוכנה לפריסה ב-
[Streamlit Community Cloud](https://streamlit.io/cloud) - כך שכל עמיתי
המשרד ניגשים לכתובת קבועה אחת באינטרנט, בלי תלות במחשב אישי דלוק או ברשת
המשרד.

**שלבי הפריסה:**

1. ודאו שה-`.env` וה-`.streamlit/secrets.toml` (אם יש לכם עותק מקומי) **לא**
   נכנסו למאגר - שניהם ב-`.gitignore` כבר, אבל שווה לוודא עם `git status`
   לפני push ראשון.
2. דחפו (push) את המאגר ל-GitHub.
3. ב-[share.streamlit.io](https://share.streamlit.io): "New app" → בחרו את
   ה-repo וה-branch → Main file path: `streamlit_app.py`.
4. לפני (או אחרי) ה-Deploy, תחת App settings → **Secrets**, הדביקו:

   ```toml
   ANTHROPIC_API_KEY = "sk-ant-..."
   APP_PASSWORD = "בחרו-כאן-סיסמה-משותפת"
   ```

   (ראו `.streamlit/secrets.toml.example` בשורש הפרויקט לפורמט המדויק.)
5. לחצו Deploy. הפלטפורמה מתקינה לבד את `requirements.txt` ונותנת כתובת
   קבועה בסגנון `https://<שם-שבחרתם>.streamlit.app` - זו הכתובת לשיתוף עם
   עמיתים, יחד עם הסיסמה מ-Secrets.

**שימו לב - אחסון בענן אינו קבוע:** בניגוד להרצה מקומית, מערכת הקבצים
ב-Community Cloud מתאפסת בכל הפעלה מחדש של האפליקציה (למשל אחרי push חדש
לקוד, או "reboot" יזום). כלומר `output/ריכוז_תעודות.xlsx` עלול פשוט להיעלם
בהפעלה מחדש, ו"הוספה לקובץ הקיים" (ולא דריסה) שמתוארת למעלה תעבוד רק בין
עיבודים באותה הפעלה רציפה של האפליקציה - לא לאורך זמן. מומלץ להוריד
(כפתור "הורדת קובץ Excel") אחרי כל סבב עיבוד ולשמור את הקובץ מחוץ לאפליקציה,
ולא להסתמך על צבירה ארוכת-טווח בענן.

## שדות שמחולצים

**עמודות ליבה** (תמיד מוצגות בטבלה הראשית ובקובץ ה-Excel): תאריך (יום/חודש/
שנה מלא), מספר תעודה/אסמכתא, אתר קולט, אתר/מקור, סוג הפסולת (מרשימה סגורה),
כמות (נטו), יחידת מידה, מרחב, רמת ביטחון, הערות, קובץ מקור.

**שדות מעקב פנימי** (נאספים ונשמרים תמיד, אך לא מוצגים כברירת מחדל - ניתן
להציג ב-Streamlit דרך תיבת הסימון "הצג פרטים נוספים", ותמיד זמינים בגיליון
Excel נפרד "מעקב פנימי"): מס' רכב, שם נהג, שעת כניסה, שעת יציאה, משקל ברוטו,
משקל טרה.

**זוגות מסמכים והצלבה:** אצל חלק מהספקים מופיע דפוס של שני מסמכים סמוכים
לאותה פעולת פינוי - "תעודת שקילה/משלוח" ממוחשבת ו"אישור ביצוע עבודה/הטמנה"
כתוב-יד. המערכת מזהה את הדפוס הזה לפי מבנה/כותרות המסמך (לא לפי שם ספק
קבוע), ומצליבה בין השניים: מספר אסמכתא, כמות ותאריך. אי-התאמה מסמנת את שתי
השורות ברמת ביטחון "נמוכה" עם הערה מפורטת. בנוסף, כשמסמך בודד מכיל גם ברוטו
וגם טרה, נבדקת סבירות: ברוטו − טרה = נטו (±1 ק"ג).

**טקסט עברי שנקרא הפוך (RTL):** אם שם ספק/אתר/נהג נקרא במהופך (תקלת קריאה
ידועה במודלי ראייה על טקסט RTL), המערכת מנסה לזהות זאת ולתקן אוטומטית תוך
השוואה לרשימת שמות מוכרים מההיסטוריה, ומסמנת ברמת ביטחון מתאימה גם כשאין
רשימת ייחוס להשוואה.

הרשימה המלאה, כולל הרשימות הסגורות (סוגי פסולת/מרחבים/רמות ביטחון) והתיאורים
שנשלחים למודל, מוגדרת במקום אחד: `app/fields.py`.
